# Pulpet 🐱

Prosta platformówka 2D w przeglądarce o grubym kocie, który zbiera rybki.
A simple 2D browser platformer about a chubby cat collecting fish.

## ▶️ [Zagraj / Play](https://renainouta.github.io/pulpet/)

**Sterowanie / Controls:** ← → / A D – ruch / move · Spacja / ↑ / W – skok / jump · R – restart · M – dźwięk / sound
